# erdalkarahan-veri

erdalkarahan.com sitesinin güncel verileri. Site her açılışta bu dosyaları
`https://raw.githubusercontent.com/erdalladre76/erdalkarahan-veri/main/` adresinden okur;
erişilemezse Natro'daki kendi kopyasını kullanır.

| Dosya | İçerik |
|---|---|
| oranlar.json | Asgari ücret, SGK, gecikme zammı, kira artış oranı, kıdem tavanı, Pratik Bilgiler kartları |
| linkler.json | Kurumlar, Resmî Programlar ve Belge Örnekleri sayfalarının linkleri |
| yazilar.json | Yazarlar bölümündeki yazılar |
| beyan_vergi.json | Vergi beyannameleri rehberi |
| sgk_formlar.json | SGK formları ve kodlar |
| cezalar.json | Güncel vergi, SGK ve İş Kanunu cezaları |
| hesap-plani.json | Tek Düzen Hesap Planı |

Dosyalar geçerli JSON olmalıdır; değişiklik birkaç dakika içinde sitede görünür.
